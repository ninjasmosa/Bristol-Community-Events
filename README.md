This is an online event booking platform developed as part of a first-year Computer Science university module. Mainly uses Python Flask and MySQL.

Instructions to get this running are in the howtorun.txt file. You'll need MySQL and Python (plus some extra packages) installed.

## Extra stuff I used
- [Pico CSS](https://picocss.com/) made the CSS stuff a lot easier
- [Passlib](https://passlib.readthedocs.io/en/stable/) was useful for password hashing though I think I could've just used [hashlib](https://docs.python.org/3/library/hashlib.html)
